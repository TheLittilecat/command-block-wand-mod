# command_wand

Minecraft 26.2 客户端模组，灵感by"alanbecker"

## 功能

- **按住 R** 打开扇形轮盘选择技能（12 个槽位）
- **按 N** 打开配置界面编辑命令
- **右键** 释放技能
- **按住 Alt + 滚轮** 调整 `@f` 的距离

## 指令里的两个选择器

| 写法   | 含义                                    |
| ---- | ------------------------------------- |
| `@t` | 准星上的实体。距离无限，但被方块挡住时取方块前方一格            |
| `@f` | 准星上的方块。距离用 Alt+滚轮调整，被方块或实体挡住时取被挡对象的位置 |

`@f` 之后可跟原版的相对坐标后缀（最多三个轴参数），例如 `@f~ ~-1 ~`；  
命令里其余的 `~` 与 `^` 坐标同样以 `@f` 为基准解析。

技能类型有三种：

- **脉冲** — 按一次执行一条命令
- **连锁** — 执行起始指令，延迟Nt后执行结束指令
- **循环** — 按住期间按设定频率重复执行起始指令

## 环境

- Minecraft 26.2
- Fabric Loader 0.19.5+
- Fabric API
- Java 25

## 安装

1. 装好 Fabric Loader 与 Fabric API
2. 把 `command_wand-*.jar` 放进 `.minecraft/mods/`
3. 启动游戏，**手持木棍**即可使用

本模组是纯客户端模组，服务器无需安装，服务器使用无限制。

## 构建
